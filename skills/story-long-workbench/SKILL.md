# 长篇小说工作台

按用途把选题、分析、写作与交付接成同一个长篇入口。可以从任一阶段进入，不要求从扫榜开始。

## 执行约定

- 只加载下表命中的模块及它列出的当前阶段资料，不预读整套资料。模块的 `guide.md` 是流程说明，不是另一个需要安装的 skill。
- `modules/...` 从本 SKILL.md 所在目录解析；模块文档中的 `references/...`、`scripts/...` 和 `{skill 根}` 从该模块目录解析。跨模块旧名称路径已转成 `modules/...`，不要搜索或调用原来的八个 skill。运行命令时使用脚本绝对路径与项目绝对路径，故事产物写入作者项目，不写进技能目录。
- 默认由当前会话直接执行。分析按连续章节块串行处理；审查默认 solo。无需 `.story-deployed`、自定义 agent 或额外 setup skill。仅用户明确要求多助手且当前工具支持时，才按模块的可选委派说明执行；缺少助手直接继续，不能让作者先安装环境。旧部署版本只作兼容信息，不作内容工作前置。
- 当前请求决定对象、范围、字数、人称和停点。只讨论或只做大纲就交付该层级；已经明确授权的阶段连续完成，不因模板中的通用询问重新索要同一授权。真正缺少会改变结果的信息或遇到作者尚未决定的剧情分歧时，才集中询问。
- 原文、项目设定、已确认剧情与本书文风优先；不编造榜单、正文证据、平台规则或已完成进度。参考作品与本书续写基线分开，导入自己的书不会自动变成对标书。
- 写作、改稿前按模块加载文风裁决；只检测、只审查不改正文。需要去味时才进入去味模块，不为完成一条请求自动扫榜、拆整本、润色或生成封面。
- 生图/改图先使用用户本任务已指定的方式；未指定时先询问「Image2 API 还是内置 image_gen 模型」。同一任务/批次沿用选择，不自行切换或设置备用通路。只写封面方案或提示词无需生图。
- 联网采集、图片工具和 Python/Node 按所选操作使用。实时市场信息、平台尺寸与上传规则在实际需要时核对来源和日期；历史参考不能冒充现行规则。浏览器采集能力缺失时，使用当前可用的网页工具或用户提供的数据，说明样本限制。
- 已有项目先读当前书、落盘进度及源文件，再续接缺失步骤。原文备份与已有有效成果保留；不用旧对话记忆替代文件。除非用户要求，不自动向 GitHub 或小说平台发布。

## 按需求进入

| 当前需求 | 先完整读取 | 关键交付与停点 |
|---|---|---|
| 扫榜、市场方向、选题 | [扫榜流程](modules/scan/guide.md) | 榜单采样、聚合与选题决策；无上期数据不写涨跌趋势 |
| 拆书、黄金三章、完整拆解、分析续跑、灵感库 | [拆文流程](modules/analyze/guide.md) | 章节索引、事实摘要、结构/情绪/人物/文风；只分析指定范围 |
| 只聊结构、定设定、全书大纲、卷纲、点名章细纲 | [写作流程](modules/write/guide.md) | 按请求停在对应规划层，不自动转正文 |
| 开书、写第N章、日更、续写、重写正文 | [写作流程](modules/write/guide.md) | 完成本轮写前必读与追踪检查；只写授权章节范围 |
| 导入自己的长篇、继续导入 | [导入流程](modules/import/guide.md) | 保留源文，生成可续写的设定、大纲、正文与追踪 |
| 去AI味、润色、仅检测 | [去味流程](modules/deslop/guide.md) | 只改表达、不改剧情；仅检测只出报告 |
| 审查一章、多章、整卷 | [审查流程](modules/review/guide.md) | 有引文和位置的问题报告；不修改正文 |
| 小说封面、封面提示词、改封面 | [封面流程](modules/cover/guide.md) | 按当前阶段交付方案/提示词或图片，先落实生图方式 |

## 长篇交接

扫榜的 `选题决策.md` 可交给拆文验证和开书；拆文产物保存在 `拆文库/{书名}/`，写作项目只按需引用。导入生成自己的写作工程后，按作者后续要求接入写作。正文、设定与细纲分文件，追踪由模块脚本的事务维护，禁止手改派生视图。

只要求开书时按已约定的规划层完成，最远停在首批细纲；明确要求写首章时只补该章必要前置。单章默认一章，未指定数量的日更按写作模块的2–3章批次处理，超出范围在下轮续接。

裸调用时显示当前项目状态及可执行阶段，让作者选择；不能把裸调用自动解释为写正文。明显是短篇时说明 `story-short-workbench` 的适用性，不静默把已有工程转成另一种结构。
