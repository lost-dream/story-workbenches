# 小说封面

本模块适用于长篇和短篇。先判断当前请求只要方案、提示词，还是要实际生成/修改图片。

## 输入与通路

从当前项目及请求读取书名、笔名、题材、简介、平台、输出目录与已有参考图；不要编造书名或笔名，缺必需文字时集中补问。目录未指定时采用项目内 `covers/{书名}/` 并告知，不为普通路径选择暂停。

实际生图/改图：用户本任务已指定 Image2 API 或内置 image_gen 时沿用；未指定时先询问两者选择。收到选择后使用相应工具/技能，整个批次沿用，失败时保留方案和提示词、说明原因，不自行切换。只写提示词时直接交付，不必调用图像工具。

用户要求参考图编辑时先查看本地图片；按所选工具规定传入原图，不凭文件名猜图像内容。透明背景按当前请求处理。

## 视觉设计

按 [封面风格](references/cover-styles.md) 读取相关题材与平台的视觉映射；作者明确方向优先。书名不足以判题材时读简介，不因零命中一律归为都市。风格表是候选素材，不强制每个封面都加光效或装饰。

提示词由文字、风格、画面三层组成：

1. 文字：原样写入书名和笔名，明确字体、大小层级、颜色、位置及可读性，中文文字保持原样。
2. 风格：采用适合题材的平台方向，同时服从作者偏好。
3. 画面：明确人物/物件、服饰、姿态、构图、前后景和光色。按请求提供少量构图候选，不因列出三个候选就自动生成三张。

提示词骨架（可按所选模型语言要求改写）：

```text
Chinese novel cover design, [风格].
Exact title text '[书名]' in [字体/颜色/层级/位置].
Exact author name '[笔名]' in [与书名协调的字体/颜色/位置].
[主体与动作]. [背景层次]. [色彩与光线].
Portrait [目标比例], keep all lettering inside an inner safe area away from edges.
```

## 尺寸与交付

用户给出上传规格时按其执行。未给出且要交付上传版时，核对目标平台当前官方规格；风格参考中的历史尺寸（例如番茄600×800、3:4）仅作待核对值。只做概念图可采用说明过的竖版比例。

生成后目视检查书名/笔名逐字正确、文字完整、题材与构图匹配、实际尺寸与比例满足目标。保留原图，不用会切掉文字的居中裁剪强行凑尺寸。需要编辑或重排时仍使用本任务所选图像方式；只有用户要求额外导出处理时才按允许的本地工具执行。

交付封面预览、实际文件或工具返回的结果，以及一句构图说明；尚未生成时明确交付的是方案/提示词，不能说封面已经做好。
