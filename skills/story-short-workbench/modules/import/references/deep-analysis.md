# 导入场景的分析交接

先读导入记录，来源、篇幅和范围沿用已确认值。执行本工作台根目录下 `modules/analyze/guide.md`：长篇用统一索引与批次管道，短篇用本包分析适配，不调用外部旧 skill。

已有可验证成果直接复用，只补导入当前需要的缺失范围；新任务按源文实际情况执行。导入范围已授权时不在前三章后重复停靠询问。不把未读范围登记成已分析。

长篇超过200章读取 [特殊情况](import-special-cases.md)。短篇残稿按分析模块的 `import_ready` 判定已有范围能否迁移，不把残稿当全篇Stage 6验收通过。

分析源与外部对标分离，保留原文和历史产物。产物与来源一致且足够迁移后更新导入记录，继续结构迁移；否则说明具体缺口并从模块进度恢复。
